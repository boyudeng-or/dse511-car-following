## Using the scorer

```python
from carfollow import FULL_PATH, IDM, KeepSpeed, compare, evaluate, load_table, split_by_group

table = load_table(FULL_PATH)
train, test = split_by_group(table, test_group=0)   # train your model on `train` only

scores = evaluate(IDM.calibrated(), test)           # one dict: every score with a 95% interval
compare([KeepSpeed(), IDM.textbook(), my_model], test)   # the comparison table, one row per model
```

Any object with `name` and `accel(history)` works (`check_model` tells you if
yours fits). Score a model only on driver groups it was not trained on.

## The scores

| Key | Score | Meaning | Unit |
|---|---|---|---|
| `step_rmse` | Step | RMSE of `accel(history)` against the real `accel_mps2`, given the real last 3 s | m/s² |
| `step_mae`, `step_r2` | Step | MAE and R² on the same rows | m/s², – |
| `drive_gap_rmse` | Drive | RMSE between simulated and real gap over every step of every 30 s rollout | m |
| `drive_crashes` | Drive | rollouts in which the simulated gap reached zero | count |
| `drive_crash_rate` | Drive | `drive_crashes / n_drives` | – |
| `spread_distance` | Spread | Wasserstein-1 distance between simulated and real time headway (gap / speed) | s |
| `<score>_lo`, `<score>_hi` | | 95% bootstrap interval for `step_rmse`, `drive_gap_rmse`, `drive_crash_rate`, `spread_distance` | |
| `n_rows`, `n_drives`, `n_drivers` | | how much was scored | count |

**Step rows.** Every row with a full 3 s of real history whose next step is
still in the pair: rows 29 to n−2 of each pair. These are the rows lanes B and
C already report on, so their numbers can be compared with the scorer's.

**Drive.** One rollout per pair. It starts at row 29 from the real position,
speed and 3 s history. Every 0.1 s the model picks an acceleration, the car
moves with `kinematics.advance`, and the new gap, speed and closing speed
(behind the real leader, who drives exactly as in the data) are appended to
the history. So a model with memory sees its own driving, not the real
driver's. A rollout lasts 30 s, or until the pair ends if that comes first,
or until the gap reaches zero: that counts as a crash and ends the rollout.
The gap error pools every simulated step of every rollout.

**Spread.** At the same rollout steps, compare the distribution of simulated
time headways with the real ones. Steps where either car moves at 1 m/s or
less are left out, because gap / speed blows up near standstill.

**Error bars.** Drivers are resampled with replacement (200 times, fixed seed
511): drivers are the unit the groups are split by. Every model is resampled
the same way, so intervals of different models on the same table are directly
comparable. `n_boot=0` skips them.

**Faster scoring (optional).** A model may also define
`accel_batch(histories)`, taking an `(n, 30, 3)` array and returning `n`
accelerations. The scorer then calls it once per batch instead of `accel` once
per row, after checking on 25 real histories that both give the same answer.
Lane B's `MemorylessAccelerationModel` already has one.

## The simulator

```python
from carfollow import simulate, replay

roll = simulate(IDM.calibrated(), test)   # Rollouts: one row per pair, one column per 0.1 s
roll.sim_gap, roll.real_gap, roll.sim_speed, roll.real_speed, roll.crashed, roll.pair_ids
replay(test)                              # the same rollouts driven by the real accelerations
```

`replay` is the sanity check promised in the main README: feeding the real
accelerations through the simulator reproduces the real gaps (to the 4
decimals the CSV stores), so a perfect model scores zero Drive error.

## Checks (`tests/test_evaluate.py`)

- A table generated by IDM scores exactly zero on Step, Drive and Spread when
  IDM itself is scored; other models score above zero.
- The model sees exactly the histories `history_at` cuts, in the Step score
  and at the start of every rollout.
- A crash is counted once and ends its rollout; non-finite accelerations, an
  `accel_batch` that disagrees with `accel`, and tables that break the
  agreement are rejected.
- The headway distance matches `scipy.stats.wasserstein_distance`, with and
  without bootstrap weights.
- With data present: `replay` reproduces the real gaps within 5 cm, and the
  baselines score finite numbers. On `pairs_full.csv` v1, replaying all 8,301
  pairs gives at most 0.41 cm gap error (CSV rounding) and no crashes.

**Cross-check with lane B.** Lane B's two hand-off models, refit with lane B's
code and settings on groups 1–4, get exactly the group-0 numbers lane B's
README reports from its own local drive test: Step RMSE 0.6365 and 0.6257,
Drive gap RMSE 6.66 and 6.30 m, 28 and 80 crashes. Two separate
implementations of the rollout agree.

**Careful with Step scores of models with memory.** Speed in the table is
smoothed over 2.1 s, so the next acceleration is almost fixed by the last two
speeds. A model that just repeats the last acceleration scores the best Step
error of all and drives the worst:

```python
class KeepAccel:
    name = "keep_accel"

    def accel(self, history):
        return float((history[-1, 1] - history[-2, 1]) / 0.1)
```

On group 0: Step RMSE 0.105 (R² 0.98), Drive gap RMSE 56.9 m, 754 crashes
(46%), Spread 4.04 s. A low Step error from a model that reads the history
says little until its Drive and Spread scores are in. That is Q1.
